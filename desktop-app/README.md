# برنامج فريق الإيرادات (ديسكتوب Windows) — النسخة الأولى

يفتح المبنى، وتكتب فيه طلبك، والفريق يشتغل والمبنى يتحدث مباشرة. البيانات تبقى على جهازك وفي الدرايف.

## مين يسوي وش

| الجزء | الشغل |
|---|---|
| **Python** (`engine/revenue_engine.py`) | كل الأرقام: الاستلام، شيل الأعمدة الشخصية، التصنيف برقم الحساب، استبعاد الملغي والمكرر (x)، الجهات والقطاعات، تحديث ملف المتابعة، وفحوص Salah |
| **Ollama** (على جهازك) | مسودات ملاحظات الأقسام، ورد الزيارة التفقدية |
| **Claude** (باشتراكك عن طريق Claude Code) | قادة الأقسام يراجعون المسودات، وAziz يدقق المنطق ويحرر اللغة |
| **قفل الأرقام** | أي رقم في نص ما هو موجود في مخرجات Python يرتفع، وإذا التحرير غيّر رقم يرجع البرنامج للنص المعتمد |

## الطلبات المتاحة في النسخة الأولى

- «حدّث ملف متابعة أكتوبر» (أو أي شهر، ومعه السنة إذا تبي)
- «افحص ملفات الدرايف»: يعرض الأوراق والعناوين وعدد الصفوف بدون أي بيانات

## المخرجات

1. **مسودة** في `‎<الدرايف>/06 طباعة/<السنة-الشهر>/`: ملف المتابعة (Excel) ومذكرة PDF.
2. تضغط **اعتماد ونشر** في البرنامج، فتنتسخ إلى `‎07 معتمد ومنشور`.

ملف المتابعة نسخة جديدة من ملف الشهر السابق (القالب):
- تتحدث الخانات الثابتة بس، وأي خانة فيها معادلة تبقى كما هي (مثل البلديات = المنطقة − المدينة).
- أسماء الأوراق والأعمدة ما تتغير، فلوحة Power BI تبقى شغالة.
- الملفات الأصلية في الدرايف ما تنلمس أبداً.

## التثبيت

1. **Google Drive for Desktop**، وخل مجلد الفواتير «متاح بدون إنترنت».
2. **Ollama**، ثم نزّل نموذجاً: `ollama pull qwen3:14b`
3. **Claude Code**، وسجّل دخولك باشتراكك Max: افتح CMD واكتب `claude` مرة وحدة.
4. ثبّت البرنامج من `RevenueTeam-Setup-x.y.z.exe` (من GitHub Actions ← آخر تشغيل ← Artifacts).
   - أول مرة بيطلع تحذير SmartScreen لأن البرنامج غير موقّع: «More info» ← «Run anyway».
5. افتح البرنامج ← **الإعدادات**: حدد مجلد الدرايف والملفات الأربعة، ثم **حفظ وفحص الاتصال**.

## الإعدادات المتقدمة (أعمدة الملفات)

البرنامج يدوّر الأعمدة بأسمائها (`columns`). إذا اسم العمود في ملفاتك مختلف، أضفه للقائمة.

- `municipality_groups`: يربط كل بلدية بمجموعتها مثل «بلديات (أ)»، كما في ورقة القطاع.
- `city_markers`: الكلمات اللي تخلي الجهة «مدينة الرياض» (الافتراضي: أمانة، قطاع).
- أي عمود فيه اسم أو هوية أو جوال أو مستفيد ما يُقرأ، وإذا انربط بحقل مطلوب يوقف المحرك بدل ما يقرأه.

## اللي باقي (المراحل الجاية)

- المقدر والمستهدف في «الإيراد الشهر الحالي» تحتاج ملف المستهدفات.
- ملفات الوزارة: الاستقطاع ÷ 0.85، والبيان التفصيلي، والتكرار.
- المحللون الأربعة وVandaik (3 من 4)، وتقرير الصحيفة الكامل، وتذكير الإيميل.
- تقرير الرخص التجارية (13 خطوة)، والأثر والسيناريوهات.

## للمطوّر

```
npm install
python3 samples/make_sample_data.py   # بيانات وهمية بالكامل
npm test                              # السلسلة كاملة بنموذج وهمي
npm start                             # البرنامج (يحتاج شاشة)
npm run dist:win                      # المثبّت (على Windows أو في GitHub Actions)
```

`npm start` يبني المبنى من `revenue-team/building.html` (المصدر الوحيد)، ويحقن فيه الجسر المحلي وشريط الطلبات.

**ممنوع رفع أي بيانات حقيقية للمستودع لأنه عام.** الإعدادات والمخرجات تنحفظ في مجلد البرنامج على الجهاز (`%APPDATA%`) وفي الدرايف فقط.
